# Мой школьный архив

В этом репозитории сохранены два моих самых первых тренировочных проекта, на которых я изучал синтаксис языка, работу с Windows API и файловой системой:

1. **Console Guess Number Game**
Игра "Угадай число". Моя самая первая попытка работы с библиотекой `fstream` для записи рекордов локальных сессий (с обработкой профилей по никнейму пользователя), а также базовая генерация рандомных чисел `random_shuffle` и встроенный скрытый чит-код разработчика.

2. **Dota 2 Invoker - Console Memory Trainer**
Мой следующий, более сложный консольный симулятор. Написан без графики для отработки мышечной памяти кнопок. Тут я реализовал бесконечный цикл через `while()`, захват быстрых нажатий с клавиатуры через `getch()`, скрытие системного курсора, структуру нативного текстового меню, подсчет таймингов скорости ввода `clock()` и продвинутую систему сортировки доски лидеров (`record.txt`).
